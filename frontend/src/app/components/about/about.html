About NLP Scraper

A data-processing pipeline that automatically collects information from websites, extracts and cleans the useful text, analyzes it with NLP, and stores the results for search and analysis.

How it works

  1. Scrape — pipeline uses Playwright to pull the latest articles from TechCrunch and The Verge, running on an hourly schedule.
  2. Clean — the raw HTML is reduced to plain title/body text, author, publish date, and topics.
  3. Store — cleaned articles are upserted into MongoDB (storage), keyed by URL.
  4. Serve — app exposes a paginated REST API over the stored articles.
  5. Explore — this Angular app (frontend) lets you browse and read them.

What's next

Keyword extraction, sentiment analysis, and named entity recognition (NER) — to surface topics, opinions, people, organizations, and locations — are planned but not implemented yet.
